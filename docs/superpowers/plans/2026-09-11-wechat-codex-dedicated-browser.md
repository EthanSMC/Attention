# 专用浏览器实施计划

设计：`../specs/2026-09-11-wechat-codex-dedicated-browser-design.md`，用户已确认。
writing-plans 技能不可用，使用此项目内计划跟踪实际交付。

## 实施顺序与检查点

- [ ] 1. 本地工具契约与任务状态机：严格输入、账号/来源绑定、30 分钟生命周期、
  串行操作、60 秒截止、取消/撤销、验证后真实再读、只读状态不会触发重试。
- [ ] 2. 专用持久化 Playwright 适配器与 stdio MCP：独立 profile、受控网络、
  文本/验证识别、安全的页面操作、进程清理；不暴露任意 JS 或 browser credentials。
- [ ] 3. Attention 授权及私人补全：服务端派发短期读取授权，重新核验账号和来源；
  写入收藏级覆盖而不是共享 content；迁移、幂等与并发保护，私人状态和视图读回。
- [ ] 4. 安装与微信 Codex 接入：显式浏览器授权、锁定依赖、可选 MCP 注册、
  fail-closed 无关 MCP 隔离、浏览器故障不影响聊天，更新文档/权限/产物测试。
- [ ] 5. 消息循环：接收与 Agent 执行分离，保持单会话串行及可靠持久化，转发
  有限的正常进展而非思维链或工具输出，超时与取消不丢消息。
- [ ] 6. 回归和端到端：相关包测试/类型检查/构建；真实微信文章通过专用浏览器
  获得正文、写回并读回；验证阻塞须交代真实状态，不伪造成功。不发布部署。

## 工作区与验证约束

分支 `codex/wechat-dedicated-browser`。既有未跟踪同步副本、`.codex/` 和历史 patch
不属于本任务，不提交、删除或覆盖。提交仅逐项添加本次明确变更。
优先复用既有 URL 公网校验、内容分类/提取、服务端身份和迁移模式。
失败分支先写测试；各层通过后再启用本机能力，不能用修改权限指纹跳过授权。
本地测试不得覆盖已运行 Bridge 的登录、消息队列或日常浏览器 profile。

## 必测反例

跨账号/来源变化/过期授权、重复并发调用、已取消任务迟到结果、验证码伪正文、
截断正文、恶意跳转及 DNS 重绑定、文件/内网访问、登录资料泄露、私人摘要出现在
公开页面、人工编辑被覆盖、浏览器崩溃导致 MCP/chat 全部离线、等待期间收不到消息。
