## 已完成的修复

- 账号设置侧栏不再放置独立“会员方案”入口。会员状态保留在“账号资料”的状态卡中；没有订阅时使用蓝色“订阅”，已有订阅时使用弱化的“管理订阅”。两者都以新标签页打开 `/membership`，外链箭头与文字同尺寸并排显示。
- 设置卡片统一使用白色表面、1px 中性边框、20px 内边距和 16px 圆角；页面背景不再使用暖米色或纸张色。
- 设置侧栏、顶部“收藏链接”入口、普通按钮和弹窗关闭按钮统一提供至少 44px 的交互区域。
- “收藏链接”改为上下文弹窗，不离开当前页面；弹窗有标题关联、Escape/遮罩/关闭按钮退出、Tab 焦点循环以及关闭后的焦点还原。
- 邀请、Filter 年卡和积分使用用户可读状态文案；不再直接显示 `unavailable`、`issuer_revoked` 或“最小货币单位”等内部字段。
- 日报使用“发送时间”表达用户决策，不再使用含义不清的“送达窗口”；流程保留为“选择日报 → 设置时间和渠道”。
- 新增 `PRODUCT.md`、`DESIGN.md` 和统一 Token 约定，明确黑白中性表面、蓝色主要行动、珊瑚色人工语义，以及卡片/按钮/导航/弹窗规则。
- 账号页移除只有一个项目的“收藏”Tab；展示名与 Attention ID 合并到“个人资料”主容器，邀请、Filter 年卡和积分合并为一个增长权益面板，避免小任务卡片堆叠。

## 设计与业务规则

### 会员

会员不是设置侧栏的独立分区。设置页只展示当前状态和下一步行动：

| 当前状态 | 操作 | 视觉权重 |
| --- | --- | --- |
| Free，无有效权益 | 订阅 | 蓝色主按钮 |
| Member，有自动续费订阅 | 管理订阅 | 白底描边次按钮 |
| Member，仅有赠送/兑换权益 | 订阅 | 蓝色主按钮，说明权益来源 |

### 日报

日报设置先让用户选择一份或多份日报，再决定是否开启投递，最后设置时区、发送时间和发送渠道。未支持的渠道只展示为禁用状态，不伪造可用能力。

### 增长权益

“新用户邀请”面向所有 active 注册账号，包括 Filter；Filter 年卡签发与新用户邀请是两项独立能力，不能把年卡资格误作邀请资格。

### 设置导航

账户资料、安全、日报、连接与授权是核心分区；Filter 权益只在拥有 Filter 身份时出现。邀请、积分等增长能力嵌入账号资料，不重复占用侧栏入口。
